## 1. 背景与定位

- **公司**：梁龙科技（暂定，未注册）。家族化愿景：让普通人获得原本需要专业团队才能做到的能力。
- **产品**：帧间（前身 viral_analyzer）。一句话定位：**爆款拆解驱动的 AI 创作工作台**。
- **关键立场**：创始人背景为数据科学与大数据技术，产品走"数据驱动的创作方法论工程化"路线——用拆解数据 + AI 把编导的隐性经验翻译成可调用的模板与建议；不参与剪辑工具正面竞争（成片剪辑交给剪映等）。
- **用户**：普通创作者（个人 → 未来团队/商业剪辑）。

## 2. 核心业务闭环（数据飞轮）

```
视频源 ──► 视频拆解 ──► 结构标注 ──► 元素变异
(多平台)    分层推理     人工校准      人工调整/建议
                    │
                    ▼
              拆解元素资产库
                    │
                    ▼
              视频创作 ──► 创作者发布 ──► 数据回流(互动/涨粉)
                    ▲                        │
                    └──── 反哺判断"什么真的爆" ◄┘
```

**护城河**：自我增强的数据闭环。拆解越多 → 样本越多 → 变异建议越准 → 创作质量越高 → 回流数据反哺。纯工具类竞品难以复制。

## 4. 拆解方法论（核心资产）

### 4.1 五层分步推理（基于编导工作体系）

| 层 | 阶段 | 产出 |
|----|------|------|
| 1 | 外围建档：不看视频，依据标题/封面/标签/数据/评论定预期锚点 | 锚点+数据画像 |
| 2 | 宏观扫描：题材/人群/形式/主题，整体框架草图 | 定性+分段骨架 |
| 3 | 结构拆解：钩子/铺垫/转折/输出/CTA/情绪节点+起止时间 | 段落时间轴+结构线 |
| 4 | 内容精拆：文案转写/画面/音频/节奏 | 多模态时间轴 |
| 5 | 元素提炼：跨段抽象，元素卡片+置信度 | 元素资产 |

每层独立上下文承接，逐层推进，减少每层工作量。

### 4.2 设计原则（防幻觉/可验证）

- 多模态交叉验证（视觉/听觉/文案/互动）
- 全量时间戳对齐
- **观察与推断分离**：观察置信度高如实记录；推断必须给证据；不确定不写死
- 外围锚点校验：先外后内，锚点对撞（结构完美但数据差 → 拆漏或反面教材）
- 人工可校验可纠错：结论锚定时间轴可跳转看证据；用户修正反哺品类认知

### 4.3 品类差异化

- 不同品类拆解优先级不同（口播重文案钩子、颜值重画面节奏…），一品类一套模板
- 每品类 1-2 个编导认可的满分拆解做样本示范（few-shot）

### 4.4 质量自循环

监测元素被创作使用比例、采纳率/修正率；被高频修正区域 = 品类拆解薄弱点 → 样本反馈改进。

## 5. 产品形态决策（已拍板）

- **决策**：Web/PWA 起步（React + Vite），本地 FastAPI 后端 + PostgreSQL；未来可 Tauri 包壳上桌面。
- **理由**：用户自带 API-key，无服务器算力成本；单人最快落地；五端浏览器可访问；代码可平滑迁移原生壳。
- **数据策略**：本地优先，数据访问层抽象，为未来团队云同步预留。
