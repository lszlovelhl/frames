### 口径区分（②节奏 vs ③情绪，避免混淆）

- **节奏曲线**：剪辑与信息密度视角——段落时长占比、单位秒句数、长停顿转换次数；输入 segments/sentences，纯推导，不调 LLM。
- **情绪曲线**：内容情绪强度视角（0~10）——音频能量锚点 + 句子强度插值拟合；由 `emotion.py` / stage2 产出。

## 二、质量门规则与阈值（`quality_gate.py`，常量集中）

| 检查键 | 含义 | 阈值 | 权重 | 关键项（一票否决） |
|---|---|---|---|---|
| `core_idea` | 核心思想非空 ≥8 字且摘要 ≥30 字 | 长度阈值 | 0.15 | 是 |
| `hook_present` | 钩子总数 ≥1（段+句+库） | ≥1 | 0.15 | 是 |
| `emotion_curve` | 曲线非退化、插值占比 ≤30%、强度极差 ≥1.5 | 见常量 | 0.15 | 否 |
| `rhythm_curve` | 节奏可推导（段落≥1 且覆盖率 ≥85%） | 0.85 | 0.10 | 否 |
| `verbatim_anchor` | 原话锚定率 `quote_verbatim_rate` | ≥0.60 | 0.15 | 是 |
| `segment_coverage` | 段落覆盖句子占比 | ≥0.85 | 0.15 | 是 |
| `reusable_elements` | 积木总数 ≥1 且基线通过 | ≥1 | 0.15 | 否 |

- 总分 = Σ 权重 × 单项通过（100/0），**及格线 70**；关键项任一不过直接判 `passed=False`（防总分被宽松项拉过线）。
- 结果写入 `job.evidence["quality_gate"]`：`{passed, score, checks[], issues[], fixes[], critical_failed[], revision, thresholds}`。
