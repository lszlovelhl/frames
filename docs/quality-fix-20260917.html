2. 核心突破：L3 harness 兜底补段

问题本质：短视频常见"口播段 + 尾部纯画面段"结构（如美妆：42s 口播吐槽结束 → 42~50.6s 美妆技巧展示）。 L3 契约要求段落锚定口播行号（line_from/line_to），模型无法用行号表达无口播的画面段 → 要么硬套行号（重叠被过滤）、要么漏掉画面段。

解法（语义归模型，精确归 harness）：
L3 模型输出口播段→ harness 检测：
口播充足(≥6句) + 末段以口播收尾 + 尾部≥3s 无口播画面段未被覆盖→ 确定性追加纯画面段
（时间=口播结束~片尾，seg_type=干货）
关键判据：last.end_ms < dur_ms - 2000 且 last_asr_end ≥ last.end_ms - 500（末段确实以口播收尾）。
